I.	Introducción

El presente informe documenta el desarrollo e implementación de un sistema IoT denominado "Pastillero Inteligente", el cual fue diseñado para automatizar y mejorar la adherencia al tratamiento farmacológico de pacientes que requieren la toma de medicamentos en horarios específicos.

El proyecto integró tecnologías de hardware y software, combinando un microcontrolador ESP32 con una aplicación móvil desarrollada en Android utilizando Kotlin como lenguaje de programación. El sistema permitió la comunicación bidireccional entre el dispositivo físico (pastillero) y la aplicación móvil a través de tecnología Bluetooth, posibilitando el control remoto del mecanismo de apertura/cierre del pastillero y la programación de alarmas para recordatorios de medicación.

La solución desarrollada incorporó consideraciones de seguridad basadas en el estándar ISO 27400:2022 para dispositivos IoT, implementando mecanismos de autenticación robusta, cifrado de datos sensibles, gestión segura de sesiones y registro de auditoría de accesos.

El sistema demostró ser una alternativa viable para mejorar la calidad de vida de pacientes con tratamientos farmacológicos prolongados, adultos mayores, y personas con condiciones que dificultan el seguimiento de horarios de medicación.


II.	Objetivos

Objetivo General

Desarrollar un sistema IoT de pastillero inteligente que permita automatizar la dispensación de medicamentos y mejorar la adherencia al tratamiento farmacológico mediante la integración de un microcontrolador ESP32 con una aplicación móvil Android.

Objetivos Específicos

1.	Diseñar e implementar el circuito electrónico del pastillero utilizando el microcontrolador ESP32, integrando sensores LDR y actuadores (servomotor) para el control del mecanismo de apertura/cierre.

2.	Desarrollar una aplicación móvil Android en Kotlin que permita la comunicación Bluetooth con el dispositivo, el control manual del pastillero y la programación de horarios de medicación.

3.	Implementar un sistema de autenticación seguro basado en el estándar ISO 27400:2022, incluyendo protección contra ataques de fuerza bruta, cifrado de datos y gestión de sesiones.

4.	Integrar un sistema de alarmas que notifique al usuario sobre los horarios de toma de medicamentos y active automáticamente el mecanismo de apertura del pastillero.

5.	Validar el funcionamiento del sistema mediante pruebas de conectividad, respuesta de sensores y actuadores, y usabilidad de la aplicación móvil.


III.	Uso de Microcontrolador, Integrando Sensores y Actuadores

3.1	Selección del Microcontrolador

Para el desarrollo del sistema Pastillero Inteligente se seleccionó el microcontrolador ESP32-WROOM-32, fundamentando esta elección en los siguientes criterios técnicos:

Requisitos de la aplicación:
•	Conectividad inalámbrica Bluetooth Classic para comunicación con dispositivos móviles Android
•	Capacidad de procesamiento para manejar múltiples tareas simultáneas
•	Suficientes pines GPIO para conectar sensores y actuadores
•	Bajo consumo energético para operación prolongada
•	Costo accesible y amplia disponibilidad

Características del ESP32:
•	Procesador: Dual-core Xtensa LX6 a 240 MHz
•	Memoria: 520 KB SRAM, 4 MB Flash
•	Conectividad: WiFi 802.11 b/g/n, Bluetooth v4.2 BR/EDR y BLE
•	GPIO: 34 pines programables
•	ADC: 18 canales de 12 bits
•	PWM: 16 canales
•	Interfaces: SPI, I2C, I2S, UART
•	Voltaje de operación: 3.3V
•	Consumo: 80 mA (activo), 5 μA (deep sleep)

Justificación:
El ESP32 fue seleccionado principalmente por su capacidad Bluetooth Classic integrada, la cual permitió establecer comunicación mediante el perfil SPP (Serial Port Profile) utilizando el UUID estándar 00001101-0000-1000-8000-00805F9B34FB. Esto facilitó la implementación de una comunicación serial inalámbrica confiable con la aplicación móvil Android.

3.2	Integración de Sensores

Sensor LDR (Light Dependent Resistor)

Propósito: Detectar si el compartimento del pastillero está abierto o cerrado mediante la variación de luminosidad.

Especificaciones técnicas:
•	Tipo: Fotorresistor de sulfuro de cadmio (CdS)
•	Resistencia en oscuridad: 1 MΩ
•	Resistencia con luz: 1-10 kΩ
•	Rango espectral: 400-700 nm
•	Voltaje máximo: 150V DC

Integración con el microcontrolador:
El sensor LDR fue conectado en configuración de divisor de tensión junto con una resistencia de 10 kΩ. La señal analógica resultante se conectó a uno de los pines ADC del ESP32 (GPIO 34), permitiendo lecturas de 0 a 4095 correspondientes a 0-3.3V.

Funcionamiento:
•	Cuando el pastillero está cerrado, el LDR detecta oscuridad (alta resistencia, valor ADC bajo)
•	Cuando el pastillero está abierto, el LDR detecta luz ambiente (baja resistencia, valor ADC alto)
•	El umbral de detección se configuró en 2048 (50% del rango)

La aplicación móvil muestra en tiempo real el valor del sensor LDR, permitiendo al usuario verificar el estado del pastillero.

3.3	Integración de Actuadores

Servomotor SG90

Propósito: Controlar el mecanismo de apertura y cierre de la tapa del pastillero.

Especificaciones técnicas:
•	Modelo: Tower Pro SG90
•	Torque: 1.8 kg·cm (4.8V)
•	Velocidad: 0.1 s/60° (4.8V)
•	Voltaje de operación: 4.8-6V
•	Rango de rotación: 0-180°
•	Señal de control: PWM (50 Hz)
•	Peso: 9 g

Conexión con el microcontrolador:
•	Cable naranja (señal): GPIO 13 del ESP32
•	Cable rojo (VCC): 5V (alimentación externa)
•	Cable marrón (GND): Tierra común

Funcionamiento:
El servomotor fue controlado mediante señales PWM generadas por el ESP32:
•	Posición 0° (cerrado): Pulso de 1 ms
•	Posición 90° (abierto): Pulso de 1.5 ms

Los comandos "abrir" y "cerrar" enviados desde la aplicación móvil vía Bluetooth activan las posiciones correspondientes del servomotor.

IV.	Empleo de Antenas Inalámbricas

3.6	Selección de Antenas

Para el sistema Pastillero Inteligente se utilizó la antena integrada del módulo ESP32-WROOM-32, la cual es una antena PCB de tipo meandered inverted-F.

Requisitos de la aplicación:
•	Alcance mínimo de 10 metros en interiores
•	Compatibilidad con Bluetooth Classic (BR/EDR)
•	Bajo consumo energético
•	Tamaño compacto para integración en el enclosure del pastillero
•	No requerir componentes externos adicionales

Características de la antena integrada:
•	Tipo: Antena PCB integrada (Inverted-F)
•	Frecuencia: 2.4 GHz (banda ISM)
•	Ganancia: 2 dBi
•	Patrón de radiación: Omnidireccional
•	Impedancia: 50 Ω
•	VSWR: <2:1

Justificación:
Se optó por utilizar la antena integrada del ESP32 debido a:
1.	Simplicidad de implementación (no requiere conexiones externas)
2.	Alcance suficiente para el caso de uso doméstico (10-15 metros)
3.	Reducción de costos y tamaño del dispositivo
4.	Confiabilidad probada del diseño de Espressif

Para aplicaciones que requieran mayor alcance, el ESP32-WROOM-32 dispone de un conector U.FL para antena externa.

3.7	Integración con el Microcontrolador

Procedimiento de integración:

1.	La antena PCB está integrada en el módulo ESP32-WROOM-32, por lo que no requiere conexiones físicas adicionales.

2.	Se consideraron las siguientes recomendaciones de diseño PCB:
•	Zona de exclusión de 15mm alrededor de la antena
•	Plano de tierra sólido debajo del módulo (excepto área de antena)
•	Distancia mínima de 10mm a componentes metálicos

3.	Orientación del módulo:
•	La antena se ubicó hacia el exterior del enclosure
•	Se evitaron materiales metálicos en la dirección de radiación principal

Configuración del hardware Bluetooth:
El stack Bluetooth del ESP32 fue inicializado mediante la librería BluetoothSerial de Arduino/ESP-IDF, configurando el dispositivo como servidor SPP.

3.8	Configuración y Programación

Inicialización Bluetooth en ESP32:

#include "BluetoothSerial.h"

BluetoothSerial SerialBT;

void setup() {
    Serial.begin(115200);
    SerialBT.begin("ESP32_Pastillero");  // Nombre del dispositivo
    Serial.println("Bluetooth iniciado. Esperando conexión...");
}

Manejo de comandos recibidos:

void loop() {
    if (SerialBT.available()) {
        String cmd = SerialBT.readStringUntil('\n');
        cmd.trim();
        if (cmd == "abrir") {
            abrirPastillero();
            SerialBT.println("OK: abriendo");
        } else if (cmd == "cerrar") {
            cerrarPastillero();
            SerialBT.println("OK: cerrando");
        }
    }
    
    // Envío periódico de lectura LDR
    static unsigned long lastLDR = 0;
    if (millis() - lastLDR > 1000) {
        int valorLDR = analogRead(34);
        SerialBT.println("LDR=" + String(valorLDR));
        lastLDR = millis();
    }
}

La aplicación móvil utiliza el API Bluetooth de Android para establecer la conexión mediante el perfil SPP:

3.9	Consideraciones de Seguridad

Medidas implementadas:

1.	Autenticación de dispositivo:
•	El emparejamiento Bluetooth requiere confirmación manual del usuario
•	Se utiliza el modo de seguridad 4 de Bluetooth (SSP - Secure Simple Pairing)

2.	Sin transmisión de datos sensibles:
•	Los comandos transmitidos (abrir/cerrar) no contienen información personal
•	Los datos de medicación se almacenan localmente en el dispositivo móvil

3.	Alcance limitado:
•	El alcance Bluetooth de ~10 metros limita naturalmente el área de ataque

Medidas recomendadas para implementación futura:

1.	Cifrado de comunicaciones:
•	Implementar cifrado AES-128 a nivel de aplicación
•	Agregar autenticación mediante token compartido

2.	Lista blanca de dispositivos:
•	Almacenar MACs autorizados en memoria del ESP32
•	Rechazar conexiones de dispositivos no registrados

3.	Timeout de conexión:
•	Desconectar automáticamente tras período de inactividad
•	Limitar número de intentos de conexión fallidos

4.	Actualización de firmware OTA segura:
•	Implementar verificación de firma digital para actualizaciones
•	Utilizar canal cifrado para transmisión de firmware

fun readBluetoothData(inputStream: InputStream) {
    val buffer = ByteArray(1024)
    while (isConnected) {
        val bytes = inputStream.read(buffer)
        val data = String(buffer, 0, bytes)
        runOnUiThread {
            if (data.startsWith("LDR=")) {
                updateLDRValue(data.substringAfter("="))
            } else {
                appendMessage("Recibido: $data")
            }
        }
    }
}

5.	Programación de alarmas:
private fun programarAlarma(nombre: String, dosis: String, hora: String) {
    val alarmManager = getSystemService(Context.ALARM_SERVICE) as AlarmManager
    val intent = Intent(this, AlarmReceiver::class.java).apply {
        putExtra("medicamento", nombre)
        putExtra("dosis", dosis)
    }
    val pendingIntent = PendingIntent.getBroadcast(
        this, requestCode++, intent, 
        PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE
    )
    
    val calendar = Calendar.getInstance().apply {
        set(Calendar.HOUR_OF_DAY, hora.split(":")[0].toInt())
        set(Calendar.MINUTE, hora.split(":")[1].toInt())
    }
    
    alarmManager.setRepeating(
        AlarmManager.RTC_WAKEUP,
        calendar.timeInMillis,
        AlarmManager.INTERVAL_DAY,
        pendingIntent
    )
}

VII.	Conclusiones

El desarrollo del sistema Pastillero Inteligente demostró la viabilidad de implementar soluciones IoT accesibles para mejorar la adherencia al tratamiento farmacológico. La integración del microcontrolador ESP32 con la aplicación móvil Android permitió crear un sistema funcional que cumplió con los objetivos planteados.

Logros Principales:

1.	Se diseñó e implementó exitosamente un circuito electrónico basado en ESP32 que integra un sensor LDR para detección de estado y un servomotor para el mecanismo de apertura/cierre del pastillero.

2.	Se desarrolló una aplicación móvil Android en Kotlin con tres módulos principales: autenticación segura, control del dispositivo y programación de horarios de medicación.

3.	Se implementaron controles de seguridad basados en ISO 27400:2022, incluyendo protección contra fuerza bruta, cifrado de datos sensibles, gestión de sesiones y registro de auditoría.

4.	La comunicación Bluetooth entre el dispositivo y la aplicación funcionó de manera estable, con tiempos de respuesta menores a 1 segundo para comandos de control.

5.	El sistema de alarmas permite programar recordatorios de medicación con apertura automática del pastillero, mejorando la experiencia del usuario.

Aprendizajes Obtenidos:

La modularización del código (activities separadas para login, búsqueda y control) facilitó el desarrollo y mantenimiento de la aplicación. El modo de simulación resultó invaluable para el desarrollo y pruebas sin necesidad de hardware físico disponible.

La implementación de corrutinas de Kotlin simplificó el manejo de operaciones asíncronas como la comunicación Bluetooth. Los estándares de seguridad IoT (ISO 27400) proporcionan un marco útil para implementar medidas de protección en dispositivos conectados.

Limitaciones Identificadas:

El alcance Bluetooth (~10 metros) limita la movilidad del usuario respecto al pastillero. La dependencia de un smartphone Android excluye a usuarios de otros ecosistemas móviles. No se implementó sincronización en la nube, limitando el acceso remoto y el respaldo de datos.

Trabajo Futuro:

Para la evolución del proyecto se recomienda:
•	Migrar a conectividad WiFi para mayor alcance y funcionalidades cloud
•	Desarrollar versión iOS para ampliar la base de usuarios
•	Implementar múltiples compartimentos para medicación semanal
•	Integrar con sistemas de historia clínica electrónica
•	Obtener certificaciones para uso como dispositivo médico

El Pastillero Inteligente representa un aporte significativo en el ámbito de la salud conectada, demostrando que es posible desarrollar soluciones IoT accesibles que mejoren la calidad de vida de pacientes con tratamientos farmacológicos prolongados.
